###  Cheatsheet for IntelliJ IDEA when using the **VS Code Keymap** plugin.

## 🧭 Navigation

| Action                                    | Shortcut                                 |
| :---------------------------------------- | :--------------------------------------- |
| **Go to previous / next location**        | `Alt + Left Arrow` / `Alt + Right Arrow` |
| **Go to previous / next tab**             | `Ctrl + Page Up` / `Ctrl + Page Down`    |
| **Go to top / bottom of file**            | `Ctrl + Home` / `Ctrl + End`             |
| **Switch between recent editor tabs**     | `Ctrl + Tab` / `Ctrl + Shift + Tab`      |
| **Highlight file in Project tool window** | `Alt + F1`                               |
|                                           |                                          |


---

## ✏️ Editing

| Action                                 | Shortcut                              |
| :------------------------------------- | :------------------------------------ |
| **Copy current line downward**         | `Shift + Alt + Down Arrow`            |
| **Move current line up / down**        | `Alt + Up Arrow` / `Alt + Down Arrow` |
| **Rename variable and all references** | `F2`                                  |
| **Reformat code**                      | `Shift + Alt + F`                     |
| **Extract variable from expression**   | `Ctrl + .` or `Ctrl + Alt + V`        |
| **Remove unused imports from file**    | `Shift + Alt + O`                     |

---

## 💻 Terminal & Tools

| Action                         | Shortcut         |
| :----------------------------- | :--------------- |
| **Toggle integrated terminal** | `Ctrl + \``      |
| **Open UML class diagram**     | `Ctrl + Alt + U` |
