### Sliding Window Technique Types:
- Fixed window
- Variable window

### Use Scenarios & Rules:

#### Variable Sliding Window Works When:
- All numbers are **positive**
- Condition is **<font color="#ffc000">range-based</font>** ( $< K$, $\le K$ )

#### Variable SWT Fails When:
- Negative numbers present (we cannot adjust window, because future value can be negative)
- Exact match needed ($== K$) (e.g. count subarray of sum $K$)
  - *Example:*
    - Longest Subarray With sum $K$
    - Count Subarray of sum $K$
